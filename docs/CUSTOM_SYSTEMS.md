# Custom Systems

## Arcane Syntax

Arcane Syntax converts Build a Spell from a random-unlock system into a researched magical language.

### Learning model

- **Cast** is learned from the Worn Wand.
- Every other delivery, effect, and modifier has a distinct Inscribed Rune.
- Right-clicking a crafted rune consumes it and permanently teaches that exact component.
- A duplicate rune is not consumed if the player already knows the component.

### Progression

1. **Foundation** — Worn Wand, Blank Runes, and early Arcane Workbench inscriptions.
2. **Structured** — Carved Wand; a mixture of Arcane Workbench inscriptions and Occultism rituals for concepts involving memory, address, delegated intent, obedience, or binding.
3. **Infused** — Runic Wand and Arcane Altar; powerful components made through Thaumaturge infusion.
4. **Forbidden** — The Unsealed Grammar; six capstone components using eldritch research and rare materials: Teleport, Summon, Double, Echo, Split, and Fill.

The full release package contains the component catalog and exact recipes for all 75 learned components.

### Balance changes

- Blank Rune essence gain is disabled.
- Blank Runes no longer randomly transform into Spell Runes.
- Base spell radius is 2.
- Damage multiplier is 2.
- Break + Fill has a controlled radius and block budget.
- Build a Spell's obsolete starter book is disabled.

## Draconic Artifice

Draconic Artifice makes Dragonsteel a late magical-engineering achievement.

- Dragonforge bricks use Dreadstone.
- The Dragonforge **Aperture** focuses and admits dragon breath.
- The Dragonforge **Core** contains the heart and converts the breath into a stable forging process.
- Both components are assembled with the Thaumaturge Infusion Matrix using Thaumium and other magical materials.
- Thaumium, rather than iron, is transformed into Dragonsteel.
- Void Metal remains reserved for a possible later forbidden upgrade rather than being required for baseline Dragonsteel.

## Thaumic Storage Scanning

The compatibility addon extends Thaumaturge's normal item research to Tom's Simple Storage terminals.

- Hover an item in the terminal while holding the Thaumometer on the cursor.
- Known items display their aspects.
- Unknown items display scanning progress and are validated by the server before research is granted.
- Items without an aspect definition cannot yield aspect research; that is an aspect-index limitation rather than a storage-scanning failure.
