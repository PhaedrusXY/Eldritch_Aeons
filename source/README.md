# Pack-Specific System Notes

This directory documents the pack's major custom systems. Installable builds and binary textures are distributed through CurseForge or attached release files rather than duplicated in the repository tree.

- [`arcane-syntax/`](arcane-syntax/) — Build a Spell progression, crafted-rune learning model, research tiers, and migration commands.
- [`draconic-artifice/`](draconic-artifice/) — Thaumaturge and Ice and Fire progression integration for Dragonsteel.

The complete CurseForge modpack contains additional quests, configuration, assets, and third-party projects not represented by these two system summaries alone.
