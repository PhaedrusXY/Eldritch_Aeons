This directory exposes the two small compatibility/progression fixes that are especially useful to audit directly:

- `buildaspell_shield_fix.js` — gives players nonzero max-absorption capacity so Build a Spell Shield can actually set absorption hearts.
- `dreadstone_hardness.js` — raises Dreadstone hardness to 50 so Build a Spell Break does not bypass the Dragonforge progression gate.

The archive remains authoritative for the complete v1.1 Build a Spell TOML tuning, Arcane Syntax scripts/assets, and Draconic Artifice scripts.
